## 🚀 Getting Started & Execution

### Prerequisites
- **Java SE Development Kit (JDK 17+ or JDK 21)** installed.

### Quick Build & Run Commands

#### Level 1: Beginner
```bash
# Task 1: Number Guessing Game
javac Level-1/Task-1-Text-Based-Game/src/Main.java
java -cp Level-1/Task-1-Text-Based-Game/src Main

# Task 2: Number Patterns Generator
javac Level-1/Task-2-Number-Patterns/src/Main.java
java -cp Level-1/Task-2-Number-Patterns/src Main
```

#### Level 2: Intermediate
```bash
# Task 3: Console CRUD Task Manager
javac Level-2/Task-3-CRUD-Task-Manager/src/*.java
java -cp Level-2/Task-3-CRUD-Task-Manager/src Main

# Task 4: Temperature Converter
javac Level-2/Task-4-Temperature-Converter/src/Main.java
java -cp Level-2/Task-4-Temperature-Converter/src Main
```

#### Level 3: Advanced
```bash
# Task 5: Persistent Task Manager
javac Level-3/Task-5-Persistent-Task-Manager/src/*.java
java -cp Level-3/Task-5-Persistent-Task-Manager/src Main

# Task 6: Interactive Web Scraper
javac Level-3/Task-6-Web-Scraper/src/Main.java
java -cp Level-3/Task-6-Web-Scraper/src Main
```
